## 0. วิธีใช้เอกสารนี้

- **ตัวเลขทุกตัวในหมวด 3–5 ตายตัว** ห้ามเปลี่ยนระหว่างเขียนโค้ด ถ้าจะจูนหลังเพลย์เทสต์ ให้แก้ไฟล์ JSON ของด่าน แล้วรัน replay test ใหม่ (หมวด 9)
- หน่วยเวลาในโค้ดคือ **tick** (1 tick = 0.1 วินาที) ข้อมูลด่านเขียนเป็นวินาที แล้วแปลงด้วย `ticks = round(seconds × 10)`
- คำว่า "ต้อง" = บังคับ · "ควร" = ทำถ้ามีเวลา · "ห้าม" = ห้ามทำในแจมนี้
- ชื่อคลาส ไฟล์ และข้อความในเกมเป็นภาษาอังกฤษ ส่วนคำอธิบายเป็นภาษาไทย
- ส่ง Claude Code ทีละงาน ตาม prompt ในหมวด 10.4

### ลูปการเล่นใน 1 ประโยคต่อขั้น

1. **อ่านสถานการณ์** — ด่านเริ่มแบบหยุดเวลา เห็นห้อง ปลั๊ก ตู้เบรกเกอร์ การ์ดคำขอ ไทม์ไลน์
2. **วางแผน** — ลากเครื่องใช้ไฟฟ้าไปเสียบ วางสายพ่วง (ทำได้ทั้งตอนหยุดและตอนเวลาเดิน)
3. **เดินเวลา** — กด Space แล้วเปิดเครื่อง (เปิด-ปิดและสับเบรกเกอร์ได้เฉพาะตอนเวลาเดิน)
4. **พลาด** — วงจรเกินความจุนาน 1 วินาทีจะตัด เกมบอกสาเหตุเป็นสมการ
5. **เรียนรู้** — ปลั๊กที่ดับพร้อมกันเผยว่าอยู่วงจรเดียวกัน
6. **แก้** — ย้ายปลั๊ก สลับเวลา เดินสายพ่วง รีเซ็ตเบรกเกอร์
7. **จบ** — ทุกคำขอเสร็จ = ชนะ · เลยเดดไลน์หรือตู้เย็นเสีย = แพ้ · กด R เล่นใหม่ได้ทันที

## 3. กฎเกมฉบับเต็ม

### 3.1 วัตถุในเกม

| วัตถุ | คุณสมบัติ |
| --- | --- |
| **ห้อง (Room)** | เรียงซ้ายไปขวาตามลำดับใน JSON ห้องที่ติดกันในลำดับคือ "ห้องข้างเคียง" |
| **วงจร (Circuit)** | id (A–D), ป้ายที่แสดง (อาจเป็น "?" หรือป้ายโกหก), ความจุ (แสดงเสมอ), สี, สถานะ ON/OFF |
| **เบรกเกอร์หลัก (Main)** | มีเฉพาะด่าน 5 ความจุรวมทั้งบ้าน |
| **ปลั๊ก (Socket)** | id, ห้อง, วงจรจริง, วงจรที่ "สันนิษฐาน" (ด่าน 4), เผยแล้วหรือยัง, ถูกจองหรือไม่ |
| **เครื่องใช้ไฟฟ้า (Appliance)** | ชนิด, โหลด, เปราะบางหรือไม่, ปลั๊กที่เสียบ, สวิตช์ เปิด/ปิด, ความคืบหน้า, เสร็จหรือยัง |
| **คำขอ (Request)** | เจ้าของ, เครื่อง, ห้องที่ต้องใช้, ระยะเวลาที่ต้องใช้, เดดไลน์ |
| **ตู้เย็น (Fridge)** | เครื่องตายตัว เปิดตลอด โหลด 2 ถ้าไม่มีไฟสะสมเกินขีดจำกัดของด่าน = แพ้ |
| **เหตุการณ์ตามตาราง (Event)** | เครื่องของคนอื่นบนปลั๊กที่ถูกจอง เปิดเองตามเวลา ผู้เล่นย้ายหรือเปิด-ปิดไม่ได้ |
| **โคมไฟ (Lamp)** | เครื่องมือวินิจฉัย โหลด 1 ไม่มีคำขอ เสียบได้ทุกห้อง |
| **สายพ่วง (Cord)** | จำนวนจำกัดต่อด่าน สร้างปลั๊กใหม่ในห้องข้างเคียง บนวงจรของปลั๊กต้นทาง |

### 3.2 นิยาม "มีไฟ" (powered)

เครื่องมีไฟ ⇔ **เสียบอยู่** และ **สวิตช์เปิด** และ **วงจรของปลั๊กเป็น ON**

| R11 | ถอดปลั๊ก | ทำได้ทั้งตอนหยุดและเวลาเดิน · เครื่องกลับไปถาด สวิตช์ปิด · ถอดตู้เย็นและเครื่องตามตารางไม่ได้ |
| R12 | เปิด-ปิดสวิตช์ | ทำได้ **เฉพาะตอนเวลาเดิน** · เครื่องต้องเสียบอยู่และยังไม่เสร็จ |

| R15 | ตู้เย็น | เปิดตลอด โหลด 2 · นับ tick ที่ไม่มีไฟสะสม (ไม่รีเซ็ต) · เกินขีดจำกัด = แพ้ |
| R16 | การเผยผังสายไฟ | เมื่อวงจรเปลี่ยนเป็น OFF (ตัดเองหรือถูกตัด) ปลั๊กของวงจรนั้นที่มีเครื่อง **เปิดสวิตช์อยู่** จะถูกเผย · ปลั๊กว่างหรือเครื่องที่ปิดสวิตช์ไม่ถูกเผย |
| R17 | แพ้ | (ก) ตู้เย็นไม่มีไฟสะสม > ขีดจำกัด (ข) คำขอใดยังไม่เสร็จเมื่อเวลา > เดดไลน์ (ค) เวลาเกินความยาววัน |
| R18 | ชนะ | ทุกคำขอเสร็จ และไม่แพ้ใน tick เดียวกัน |
| R19 | การหยุด | ระหว่างหยุด ซิมไม่เดิน · เสียบ ถอด วางและถอดสายพ่วงได้ทันที · เปิด-ปิดและเบรกเกอร์ถูกปฏิเสธ |

> **เดดไลน์นับอย่างไร:** คำขอที่เดดไลน์ 18 วิ (180 tick) ถ้าเสร็จพอดีที่เวลา 18.0 ถือว่าทัน แพ้เมื่อเวลา (หลังเดิน tick) มากกว่า 180

### 3.4 ลำดับใน 1 tick (`HouseSim.Step`)

ลำดับนี้ตายตัว เทสต์ทั้งหมดพึ่งพามัน

```
Step():
  1. ใช้คำสั่งในคิวตามลำดับที่เข้ามา คำสั่งผิดกฎ -> CommandRejected (สถานะไม่เปลี่ยน)
  2. เหตุการณ์ตามตาราง: now == start -> สวิตช์เปิด, now == start+duration -> สวิตช์ปิด
  3. load[c] = ผลรวมโหลดเครื่องที่มีไฟบนวงจร c
  4. วนวงจรตาม id (A, B, C, D):
        ถ้า c เป็น ON และ load[c] > cap[c]: over[c] += 1 (ครั้งแรกส่ง OverloadStarted)
        ไม่เช่นนั้น: ถ้า over[c] > 0 ส่ง OverloadCleared; over[c] = 0
        ถ้า over[c] >= 10: c = OFF, over[c] = 0, เผยปลั๊กตาม R16, ส่ง CircuitTripped
  5. ถ้ามีเบรกเกอร์หลัก: total = ผลรวม load ของวงจรที่ยัง ON
        ตรวจแบบเดียวกัน ถ้าครบ 10: ทุกวงจร OFF, เผยปลั๊ก, ส่ง MainTripped
  6. หาเครื่องที่ tick ก่อนมีไฟแต่ตอนนี้ไม่มี (และยังไม่เสร็จ, มีคำขอ):
        ส่ง ApplianceInterrupted; ถ้าเปราะบาง: progress = 0
  7. เครื่องที่มีไฟและมีคำขอที่ยังไม่เสร็จ (เรียงตาม id):
        progress += 1; ถ้า progress >= duration: done, สวิตช์ปิด, ส่ง RequestCompleted
  8. ถ้าตู้เย็นไม่มีไฟ: spoil += 1
  9. now += 1
 10. แพ้ถ้า spoil > spoilLimit หรือมีคำขอที่ยังไม่เสร็จและ now > due หรือ now > dayLength
 11. ชนะถ้าไม่แพ้และคำขอเสร็จครบ
```

**ผลเชิงเวลาที่ต้องรู้:** ถ้าโอเวอร์โหลดเริ่มที่ tick 0 วงจรจะถูกตัดระหว่างประมวล tick ที่ 9 (tick ที่ 10 ติดต่อกัน) หน้าจอแสดงเวลาตัดเป็น 1.0 วินาที

### 7.2 เสียง (สร้างด้วยโค้ด ไม่ต้องมีไฟล์)

`ProceduralAudio` สร้าง `AudioClip` ด้วย `AudioClip.Create` ที่ 44100 Hz ตอนเริ่มเกม

| ชื่อ | สูตร | ยาว | ระดับ |
| --- | --- | --- | --- |
| `click` | sine 1200 Hz, envelope ลดแบบเส้นตรง | 0.03 วิ | 0.4 |
| `buzz` | sawtooth 120 Hz + noise 10% (วน) | 0.5 วิ วน | 0.25 → 0.6 ตามตัวนับโอเวอร์โหลด |
| `clunk` | white noise ผ่าน low-pass (เฉลี่ย 8 ตัวอย่าง) + sine 80 Hz | 0.15 วิ | 0.8 |
| `chime` | sine 880 Hz 0.08 วิ แล้ว 1320 Hz 0.12 วิ | 0.2 วิ | 0.4 |
| `wrong` | square 330 Hz แล้ว 247 Hz | 0.25 วิ | 0.35 |
| `ding` | sine 1568 Hz ลดแบบ exponential | 0.4 วิ | 0.4 |
| `tick` | sine 2000 Hz | 0.02 วิ | 0.25 |
| `nope` | square 180 Hz | 0.1 วิ | 0.3 |
| `fail_small` | sine กวาด 600 → 200 Hz | 0.3 วิ | 0.4 |
| `win` | อาร์เปจโจ C5 E5 G5 C6 ตัวละ 0.12 วิ | 0.5 วิ | 0.5 |
| `lose` | sine กวาด 400 → 80 Hz | 0.8 วิ | 0.5 |

ถ้ามีเวลา (Could-have) เปลี่ยนเป็นไฟล์เสียงฟรีลิขสิทธิ์ CC0 ได้ โดยใส่ไฟล์ชื่อเดียวกันใน `Assets/Resources/Audio/` แล้ว `ProceduralAudio` ใช้ไฟล์แทนเมื่อพบ

### 8.3 ประเภทข้อมูลหลัก (`Trouble.Sim`)

```csharp
public enum CommandType { Plug, Unplug, SetSwitch, ToggleBreaker, PlaceCord, RemoveCord }
public readonly struct Command {
    public readonly CommandType Type; public readonly string A; public readonly string B; public readonly bool On;
    // A = appliance/circuit/source socket/cord socket, B = socket/target room
}

public enum SimEventType {
    OverloadStarted, OverloadCleared, CircuitTripped, MainTripped, BreakerSwitched,
    SocketRevealed, ApplianceInterrupted, RequestCompleted, FridgeSpoiled,
    CommandRejected, LevelWon, LevelLost
}
public struct SimEvent {
    public SimEventType Type; public int Tick;
    public string Circuit, Socket, Appliance;   // ที่เกี่ยวข้อง (อาจว่าง)
    public int Load, Capacity;                  // สำหรับการตัด
    public List<(string appliance, int load)> Terms; // ส่วนประกอบของผลรวม เรียงตามปลั๊ก
    public bool ProgressLost, AssumptionWasWrong;
    public LoseReason Reason; public string Message; // สำหรับ Rejected/Lost
}
public enum LoseReason { None, Deadline, FridgeSpoiled, DayOver }
public enum LevelPhase { Planning, Running, Paused, Won, Lost }
```

### 8.4 `HouseSim` (หัวใจของเกม)

```csharp
public sealed class HouseSim {
    public HouseSim(LevelData data);                 // สร้างสถานะเริ่มต้น แปลงวินาทีเป็น tick
    public int Now { get; }                          // tick ปัจจุบัน
    public LevelPhase Phase { get; }                 // ชั้น Game เป็นคนตั้ง Running/Paused ผ่าน SetRunning
    public void SetRunning(bool running);

    public bool TryApply(Command c, out string reason); // ใช้ทันที (ตอนหยุด) ตามกฎ 3.5
    public void Enqueue(Command c);                     // ใช้ตอนต้น Step ถัดไป (ตอนเวลาเดิน)
    public IReadOnlyList<SimEvent> Step();              // เดิน 1 tick ตามลำดับ 3.4

    // อ่านสถานะสำหรับ View
    public IReadOnlyList<CircuitState> Circuits { get; }
    public IReadOnlyList<SocketState> Sockets { get; }
    public IReadOnlyList<ApplianceState> Appliances { get; }
    public IReadOnlyList<RequestState> Requests { get; }
    public int MainLoad { get; } public int MainCapacity { get; } public int MainOverTicks { get; }
    public int SpoilTicks { get; } public int SpoilLimitTicks { get; }
    public int CordsLeft { get; } public int TripCount { get; }
}
```

| State | ฟิลด์ |
| --- | --- |
| `CircuitState` | `Id`, `ShownLabel`, `Capacity`, `IsOn`, `Load`, `OverTicks` |
| `SocketState` | `Id`, `RoomId`, `CircuitId`, `AssumedCircuitId`, `Revealed`, `Reserved`, `IsCord`, `CordSourceOf`, `OccupantId` |
| `ApplianceState` | `Id`, `Type`, `Load`, `Fragile`, `Fixed`, `SocketId`, `SwitchedOn`, `Powered` |
| `RequestState` | `Owner`, `ApplianceId`, `RoomId`, `DurationTicks`, `DueTicks`, `ProgressTicks`, `Done` |

กติกาการเขียน:

- ใช้ `List` และ loop ธรรมดา ไม่ใช้ LINQ ใน `Step` (กันขยะหน่วยความจำ)
- เรียงลำดับทุกที่ตาม id แบบ `string.CompareOrdinal` เพื่อให้ผลเหมือนซิม Python ทุกครั้ง
- `TryApply` ตอนหยุดต้องตรวจกฎเดียวกับ `Enqueue` (ใช้ฟังก์ชันตรวจตัวเดียวกัน)
- ซิมไม่มี `Random` ไม่มีเวลาจริง ไม่มี static state

### 8.6 ตัวตรวจข้อมูลด่าน (`LevelValidator`)

คืนรายการ error เป็นข้อความ ถ้าว่าง = ผ่าน

1. id ห้อง วงจร ปลั๊ก ไม่ซ้ำ
2. ปลั๊กอ้างห้องและวงจรที่มีอยู่ · `assumed` ว่างหรือเป็นวงจรที่มีอยู่
3. `appliance` ของคำขอและเหตุการณ์อยู่ใน `ApplianceCatalog` และไม่ซ้ำกันในด่าน
4. ทุกคำขอมีปลั๊กในห้องของตัวเองอย่างน้อย 1 ช่องที่ไม่ถูกจองและไม่ใช่ปลั๊กตู้เย็น หรือมีห้องข้างเคียงที่วางสายพ่วงได้ และ `cordCount > 0`
5. `durationSec > 0`, `dueSec ≥ durationSec`, `dueSec ≤ dayLengthSec`
6. ปลั๊กของเหตุการณ์และตู้เย็นมีอยู่ และไม่ซ้ำกัน
7. ถ้า `fridgeSocket` ไม่ว่าง `fridgeSpoilSec > 0`
8. ความจุ > 0 · `mainCapacity ≥ 0`
9. `reference` ทุกคำสั่งอ้าง id ที่มีอยู่ และ tick เรียงจากน้อยไปมาก

## ภาคผนวก A: ซิมูเลชันอ้างอิง

ซิมนี้ใช้ตรวจตัวเลขทุกด่าน และเป็นแบบอ้างอิงสำหรับพอร์ตเป็น C# ถ้า C# ได้ผลไม่ตรงกับตาราง 9.2 ให้ถือว่า C# ผิด

หมายเหตุ: ซิมนี้ **ไม่** ตรวจกฎ "เปิด-ปิดได้เฉพาะตอนเวลาเดิน" และไม่จำลองการเผย (ไม่กระทบผลแพ้ชนะ) · ปลั๊กสายพ่วงในซิมชื่อ `cord_<ต้นทาง>` ส่วนในเกมชื่อ `CORD-<ต้นทาง>`

### A.1 `sim.py`

```python
"""Reference simulation of TRIPPED! rules, used to verify level numbers.
Mirrors the locked tick order. Times in ticks (1 tick = 0.1 s)."""
T = 10  # ticks per second
OVER = 10

LOADS = {"kettle": 6, "washer": 6, "microwave": 5, "dryer": 5, "iron": 5,
         "toaster": 4, "console": 3, "fridge": 2, "phone": 1, "lamp": 1,
         "heater": 6, "tv": 2, "ac": 8}
FRAGILE = {"console"}


def s(sec):
    return round(sec * T)


class Sim:
    def __init__(self, lvl):
        self.L = lvl
        self.now = 0
        self.circ = {c: {"cap": cap, "on": True, "over": 0} for c, cap in lvl["circuits"].items()}
        self.main_over = 0
        self.sockets = {k: dict(v) for k, v in lvl["sockets"].items()}  # room, circuit
        self.occ = {}  # socket -> appliance id
        self.app = {}
        for rid, r in lvl["requests"].items():
            self.app[rid] = {"type": r["type"], "socket": None, "sw": False, "prog": 0,
                             "done": False, "req": r, "fixed": False}
        if lvl.get("fridge"):
            self.app["fridge"] = {"type": "fridge", "socket": lvl["fridge"], "sw": True,
                                  "prog": 0, "done": False, "req": None, "fixed": True}
            self.occ[lvl["fridge"]] = "fridge"
        for i in range(lvl.get("lamps", 0)):
            self.app[f"lamp{i}"] = {"type": "lamp", "socket": None, "sw": False, "prog": 0,
                                    "done": False, "req": None, "fixed": False}
        for i, ev in enumerate(lvl.get("events", [])):
            eid = f"ev{i}"
            self.app[eid] = {"type": ev["type"], "socket": ev["socket"], "sw": False, "prog": 0,
                             "done": False, "req": None, "fixed": True, "ev": ev}
            self.occ[ev["socket"]] = eid
            self.sockets[ev["socket"]]["reserved"] = True
        self.cords_left = lvl.get("cords", 0)
        self.cords = {}
        self.spoil = 0
        self.prev_powered = set()
        self.log = []
        self.result = None
        self.trips = 0

    # ---- commands
    def plug(self, a, sock):
        A = self.app[a]
        S = self.sockets[sock]
        if A["fixed"] or sock in self.occ or S.get("reserved") or S.get("cord_source"):
            raise ValueError(f"reject plug {a}->{sock}")
        if A["req"] and A["req"]["room"] != S["room"]:
            raise ValueError(f"reject room {a}->{sock}")
        if A["socket"]:
            del self.occ[A["socket"]]
        A["socket"] = sock
        A["sw"] = False  # plugging always leaves the appliance switched off
        self.occ[sock] = a

    def unplug(self, a):
        A = self.app[a]
        if A["socket"]:
            del self.occ[A["socket"]]
        A["socket"] = None
        A["sw"] = False

    def cord(self, src, room):
        if self.cords_left <= 0 or src in self.occ or self.sockets[src].get("reserved"):
            raise ValueError("reject cord")
        self.cords_left -= 1
        cid = f"cord_{src}"
        self.sockets[src]["cord_source"] = True
        self.sockets[cid] = {"room": room, "circuit": self.sockets[src]["circuit"]}
        self.cords[cid] = src
        return cid

    def remove_cord(self, cid):
        if cid in self.occ:
            self.unplug(self.occ[cid])
        src = self.cords.pop(cid)
        del self.sockets[cid]
        self.sockets[src]["cord_source"] = False
        self.cords_left += 1

    def switch(self, a, on):
        self.app[a]["sw"] = on

    def breaker(self, c):
        self.circ[c]["on"] = not self.circ[c]["on"]
        self.circ[c]["over"] = 0

    # ---- step
    def powered(self, a):
        A = self.app[a]
        if not A["socket"] or not A["sw"]:
            return False
        return self.circ[self.sockets[A["socket"]]["circuit"]]["on"]

    def step(self, cmds=()):
        for c in cmds:
            getattr(self, c[0])(*c[1:])
        # 2 scheduled events
        for a, A in self.app.items():
            ev = A.get("ev")
            if ev:
                if self.now == s(ev["start"]):
                    A["sw"] = True
                if self.now == s(ev["start"] + ev["dur"]):
                    A["sw"] = False
        # 3 loads
        load = {c: 0 for c in self.circ}
        for a in self.app:
            if self.powered(a):
                load[self.sockets[self.app[a]["socket"]]["circuit"]] += LOADS[self.app[a]["type"]]
        # 4 per circuit
        for c in sorted(self.circ):
            C = self.circ[c]
            if C["on"] and load[c] > C["cap"]:
                C["over"] += 1
            else:
                C["over"] = 0
            if C["over"] >= OVER:
                C["on"] = False
                C["over"] = 0
                self.trips += 1
                self.log.append((self.now, "TRIP", c, load[c], C["cap"]))
        # 5 main
        mc = self.L.get("main")
        if mc:
            total = sum(load[c] for c in self.circ if self.circ[c]["on"])
            if total > mc:
                self.main_over += 1
            else:
                self.main_over = 0
            if self.main_over >= OVER:
                for c in self.circ:
                    self.circ[c]["on"] = False
                self.main_over = 0
                self.trips += 1
                self.log.append((self.now, "MAIN TRIP", total, mc))
        # 6 interruptions
        pw = {a for a in self.app if self.powered(a)}
        for a in self.prev_powered - pw:
            A = self.app[a]
            if A["req"] and not A["done"]:
                if A["type"] in FRAGILE and A["prog"] > 0:
                    self.log.append((self.now, "PROGRESS LOST", a, A["prog"]))
                    A["prog"] = 0
        # 7 progress
        for a in sorted(pw):
            A = self.app[a]
            r = A["req"]
            if r and not A["done"] and self.now >= s(r.get("avail", 0)):
                A["prog"] += 1
                if A["prog"] >= s(r["dur"]):
                    A["done"] = True
                    A["sw"] = False
                    pw.discard(a)
                    self.log.append((self.now + 1, "DONE", a))
        self.prev_powered = {a for a in self.app if self.powered(a)}
        # 8 fridge
        if "fridge" in self.app and not self.powered("fridge"):
            self.spoil += 1
        # 9
        self.now += 1
        # 10 lose
        if self.L.get("fridge") and self.spoil > s(self.L["spoil"]):
            self.result = ("LOST", self.now, "fridge spoiled")
            return
        for a, A in self.app.items():
            r = A["req"]
            if r and not A["done"] and self.now > s(r["due"]):
                self.result = ("LOST", self.now, f"{a} missed deadline")
                return
        # 11 win
        if all(A["done"] for A in self.app.values() if A["req"]):
            self.result = ("WON", self.now)

    def run(self, plan, setup=()):
        """plan: dict tick -> list of commands; setup applied while paused."""
        for c in setup:
            getattr(self, c[0])(*c[1:])
        end = s(self.L["day"])
        while self.result is None and self.now <= end:
            cmds = list(plan.get(self.now, []))
            self.step(cmds)
        if self.result is None:
            self.result = ("LOST", self.now, "day ended")
        return self.result


def naive(lvl):
    sim = Sim(lvl)
    setup = []
    used = set(sim.occ)
    for a, A in sim.app.items():
        if not A["req"]:
            continue
        for sid in sorted(lvl["sockets"]):
            S = sim.sockets[sid]
            if S["room"] == A["req"]["room"] and sid not in used and not S.get("reserved"):
                setup.append(("plug", a, sid))
                used.add(sid)
                break
    plan = {0: [("switch", a, True) for a, A in sim.app.items() if A["req"]]}
    return sim.run(plan, setup), sim
```

## ภาคผนวก B: ศัพท์

| คำ | ความหมาย |
| --- | --- |
| Tick | หน่วยเวลาของซิม = 0.1 วินาที |
| วงจร (Circuit) | สายไฟชุดหนึ่งที่มีเบรกเกอร์ของตัวเอง |
| ความจุ (Capacity) | โหลดสูงสุดที่วงจรรับได้โดยไม่ตัด |
| โหลด (Load) | หน่วยไฟสมมติของเครื่อง ไม่ใช่วัตต์จริง |
| ตัด (Trip) | เบรกเกอร์ตัดไฟของวงจรนั้นทั้งหมด |
| เผย (Reveal) | ปลั๊กแสดงวงจรจริงหลังผู้เล่นได้หลักฐาน |
| สันนิษฐาน (Assumed) | วงจรที่ป้ายชวนให้เชื่อ อาจผิด |
| เปราะบาง (Fragile) | งานที่ความคืบหน้าหายทั้งหมดเมื่อไฟหาย |
| ทางแก้อ้างอิง (Reference) | ทางแก้ที่รู้ว่าชนะ ใช้เป็นเทสต์ |
| Naive | การเล่นแบบไม่คิด ใช้ตรวจว่าด่านไม่ง่ายเกินไป |
